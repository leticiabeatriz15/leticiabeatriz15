### 🧩 Sobre Mim

Desenvolvedora focada em criar soluções acessíveis, inteligentes e com impacto real. Apaixonada pela união entre **Visão Computacional**, **Inteligência Artificial** e **Desenvolvimento Web**.

* 🚀 Criadora do **Guardian A.N.Y.** (*Autista No YouTube*), uma aplicação desenvolvida para ajudar pessoas no espectro autista a identificarem níveis de estimulação sensorial em vídeos.
* 💻 Stack principal: **Python (FastAPI, OpenCV, Scikit-Learn)** no Backend e **JavaScript / Tailwind CSS** no Frontend.
* 🛠️ Experiência com **Docker**, deploy containerizado no **Render** e plataformas como **Vercel**.
* 🎯 Sempre buscando aperfeiçoar técnicas de Machine Learning e arquitetura de software modular.

### 🌟 Projeto em Destaque

<div align="center">

### 🧩 Guardian A.N.Y — Autista No YouTube
*Aplicação Full-Stack de Análise Sensorial de Vídeos via Inteligência Artificial*

[![Backend Status](https://img.shields.io/badge/Backend-FastAPI%20%7C%20OpenCV%20%7C%20Docker-9333EA?style=for-the-badge)](https://github.com/leticiabeatriz15/Guardian-A.N.Y---Backend)
[![Frontend Status](https://img.shields.io/badge/Frontend-TailwindCSS%20%7C%20JS-06B6D4?style=for-the-badge)](https://github.com/leticiabeatriz15/Guardian-A.N.Y---Frontend)

</div>

> O **Guardian A.N.Y.** extrai métricas visuais de vídeos (variação de cor, contraste cromático e agitação) usando **OpenCV** e utiliza um modelo de **RandomForest** para classificar o nível de estimulação sensorial em tempo real.
